# Triage labels

| Skill role | GitHub label | Meaning |
|---|---|---|
| needs-triage | needs-triage | Needs initial review |
| needs-info | needs-info | Needs more information |
| ready-for-agent | ready-for-agent | Defined well enough for agent work |
| ready-for-human | ready-for-human | Needs human work or judgment |
| wontfix | wontfix | Will not be addressed |

Use these exact label names when a skill refers to a triage role.

A label does not override the user's requirement to approve
proposed changes before implementation.
